# 🔍 Improved Search System (Solr + FastAPI + Frontend)

This project is a **search engine demo system** inspired by large-scale platforms like the Internet Archive. It demonstrates full-text search, indexing, and a modern search UI using Apache Solr and a Python backend.

---

## 🚀 Features

- 🔎 Full-text search using Apache Solr
- ⚡ FastAPI backend for search API
- 📚 Book dataset indexing
- 🧠 Relevance-based ranking (Solr default + BM25-style scoring)
- 🎨 Responsive frontend search UI
- 🧩 Facet-style UI layout (UI-ready for filtering expansion)
- 📱 Mobile-friendly design
